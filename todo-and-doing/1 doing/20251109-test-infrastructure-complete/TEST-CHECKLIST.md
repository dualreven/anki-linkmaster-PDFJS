## 📝 使用说明

### 更新进度

每完成一个测试，在对应的复选框前打勾：
```markdown
- [x] 已完成的测试
- [ ] 未完成的测试
```

### 记录问题

遇到问题时，在对应模块下添加注释：
```markdown
#### pdf_outline_plugin（15个）

> ⚠️ 问题：test_create_outline_item失败，原因：...
> 计划：明天修复

- [x] create_outline_item - 基本创建
- [ ] create_outline_item - 带父节点（待修复）
```

### 生成报告

定期运行测试并更新覆盖率：
```bash
# 前端
npm test -- --coverage
npm run test:coverage-report

# 后端
cd src/backend
pytest --cov=. --cov-report=html
```
